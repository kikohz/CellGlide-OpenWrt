# OpenWrt 网页界面（LuCI）功能清单

日期：2026-10-15　用途：给界面设计用的功能清单，还不是设计文档。
现状：`cellglide` 软件包已在 MX4300（OpenWrt 25.12.5）上实测通过，目前只有命令行（`cellglide pair / add / remove / list / status`，支持 `add all`）。

界面风格：LuCI 用 OpenWrt 自己的网页样式（表格、表单、卡片），和路由器后台其他页面一致，能自定义的地方有限。地图页例外，可以完全自己画。

参考现有界面：Mac 版的总览、分流、测速、地图页；iPhone 首页的状态卡片和“已连接的设备”一行。

## 第一版：后台已经支持，主要做界面

### 页面 1：状态（插件首页）

| 项目 | 内容和状态 |
|---|---|
| 手机 | 已连接（设备名或 UDID）/ 未连接 |
| 共享状态 | 在用（从几点开始）/ 不在用。不在用时写原因：没有插手机、CellGlide 没在共享、隧道没起来 |
| UDP | 正常 / 需要 App 2.3 或更新版本（这时 TCP 照常能用，DNS 由路由器解析）/ 未知 |
| 出口 IP | 在用时显示手机的出口 IP |
| 当前模式 | 指定设备（显示台数）/ 全部设备 |
| 手机不可用时 | 回到宽带 / 断网（block） |

- 大约每 5 秒刷新一次。
- 要设计的特殊情况：服务没启动（给“启动”按钮）；手机还没配对（引导去配对）。

### 页面 2：设备

- 设备列表来自 DHCP 租约：名字、IP、MAC、是否走手机，每行一个开关。
- “全部设备”总开关：打开后每行开关变灰、不可点。打开时提示：全家的系统更新、视频都会用手机流量。
- 手动添加 MAC：给不在租约里的设备（比如静态 IP）用，可以填名字。
- 可以给设备起备注名。
- 特殊情况：一台设备都没有；租约里没有名字的设备显示“-”；设备换了 IP 不受影响（按 MAC 认）。

### 页面 3：设置

- 手机不可用时：回到宽带 / 断网，两选一，配一句说明。
- DNS：IPv4、IPv6 各一个地址，带默认值（1.1.1.1、2606:4700:4700::1111），说明“仅在手机在用、且 UDP 可用时生效”。
- 端口：手机端口 9876、本机端口 19876，放进“高级”折叠。
- 服务开关：启用或停用整个功能。
- 配对按钮：点了提示“请在 iPhone 上点‘信任’”，然后显示成功或失败。

### 页面 4：关于和帮助（可以并进设置页）

- 已知限制：手机上的 CellGlide 要保持在前台；被选设备不能用 `xxx.lan` 访问局域网设备（用 IP 或 `.local` 不受影响）；外网连不进来；路由器自己的流量不走手机；一次只支持一台 iPhone。
- 版本号、文档链接。

### 不在页面上，但属于第一版

- 在手机上显示路由器：像 Mac 一样把自己的名字报给手机，手机首页“已连接的设备”显示路由器的名字。

## 第二版：要加后台功能

| 功能 | 界面上要什么 | 依赖 |
|---|---|---|
| 测速 | 一个按钮，分别经手机和经宽带测下载、上传、延迟，并排对比，保留历史 | 只改路由器 |
| 分流 | 网站列表（按服务选，比如 YouTube、Netflix，或手动填域名），选“走宽带”或“走手机”；可导入规则集 | 只改路由器；复用 Mac 版的服务目录和 rules.cellglide.com 规则集；dnsmasq 能把解析结果放进 nft 集合 |
| 按设备统计 | 每台设备经手机用了多少流量（今天、本月），排行列表 | 只改路由器（Mac 版做不到，手机上只看到一个整体） |
| 备用线路 | 开关“宽带断了自动切到手机”；显示当前走宽带还是手机，以及切换记录 | 只改路由器，配合 mwan3 |
| 网页版 3D 地图 | 可拖动的地球、连线和流动光点，右侧列出正在传数据的服务和所在地区，和手机上的一样 | 要改 iOS App：手机加一个只对本机开放的数据接口，最早随 2.4 |
| 流量提醒 | 手机流量快用完时在路由器上提醒，或者直接停用 | 需要手机提供套餐数据的接口 |

### 网页版地图的做法

- 画图：iPhone 和 Mac 上的地球是从 cobe（MIT 许可的 WebGL 地球库）移植的，网页上直接用 cobe，外观可以和 App 一致。
- 数据：用手机已经算好的数据（按服务分组、网站名、IP 归属地、实时速度、出口位置），手机代理加一个只对本机开放的接口用 JSON 交出来，路由器经 iproxy 读取。路由器不放 IP 地理库（几十 MB，闪存放不下），也不自己识别服务（DNS 已改发到手机，路由器看不到域名）。
- 这个接口以后 Linux 版也能用。

## 和 Mac 版的对照

| Mac 版功能 | 路由器上 | 说明 |
|---|---|---|
| 插线自动连接、拔线自动回原网络 | 已有 | 已实测 |
| DNS、UDP、IPv6 都经手机 | 已有 | |
| 手机端的流量统计、访问地图、本月流量、省流模式 | 自动可用 | 这些都在手机上做，省流模式在手机代理里拦截，路由器的流量同样受管 |
| 连接状态和故障提示 | 有基础 | 现在是 `cellglide status`；LuCI 做成状态页 |
| 手机首页显示已连接的设备 | 可以补 | 路由器把名字报给手机 |
| 测速 | 可以做 | 第二版 |
| 分流 | 可以做，路由器更擅长 | 第二版 |
| 按设备统计 | 路由器独有 | 第二版 |
| 宽带断了切到手机 | 路由器独有 | 第二版，配合 mwan3 |
| DNS 泄漏检测 | 不用做 | 任何设备打开官网检测页即可 |
| 诊断报告、自动更新 | 可以做 | 自动更新靠自建软件源；诊断可复用现有上传接口 |
| 菜单栏、灵动岛 | 不适用 | 对应的是 LuCI 页面 |

和 Mac 版一样的限制：上架版 App 必须在手机前台开着才能共享。

## 设计稿评审意见（2026-10-15）

设计稿：`CellGlide OpenWrt LuCI.html`（状态、设备、分流、测速、流量统计、备用线路、地图、设置八个标签页）。结构、风格和第一版 / 第二版的划分都可以照做，下面这些按实际情况改：

**和事实不符，开发时按这里做**

1. 地图不显示“经宽带”的服务。地图数据来自手机，走宽带的流量不经过手机。宽带出口这个点可以保留，但不列宽带上的服务；要列，得另做路由器端统计，而路由器看不到这些连接的网站名，只能显示 IP。
2. 域名是 `cellglide.com`，不是 `cellglide.app`。规则集地址是 `rules.cellglide.com/v1/<名字>.list`，名字用社区规则名（Netflix、YouTube 等），没有“流媒体”这种合集。
3. 包名和版本：后台包叫 `cellglide`（第一版界面同时发布时为 0.2.0），网页界面包叫 `luci-app-cellglide`；没有 `cellglided`。

**需要额外开发（设计稿没标出）**

4. 状态页的运营商名（T‑Mobile）要从手机读：Mac 版读的是手机的指标接口，路由器也可以读，第一版先不显示。手机型号用 `ideviceinfo` 直接读，第一版就有。
5. iPhone 端“USB · 3 台设备在用”：现在手机只显示电脑报来的名字和 USB 速度，显示“几台设备在用”要改 iOS（最早 2.4）。第一版显示“路由器名 · 已连接”和 USB 速度。
6. 本月套餐（状态页、设置页）要读手机的套餐设置，需要手机提供接口，和地图一样最早随 2.4。

**建议调整**

7. 分流页去掉“走手机”选项：页面只对走手机的设备生效，它们默认就走手机。只留“走宽带”。
8. 备用线路“打开时自动配置 mwan3”会改动 WAN 和 mwan3 设置，和“尽量少改路由器”冲突：打开前列出会改哪些设置，关闭时完全恢复；或者先只支持已经配置好 mwan3 的路由器。
9. 已知限制加上“一次只支持一台 iPhone”和“`.local` 名字不受影响”。

**小问题**

10. 页脚写的 OpenWrt 24.10.3，24.10 和 25.12 都支持，无所谓。
11. 状态页的几种异常情况（服务未启动、手机未配对、没插手机、没在共享、隧道没起来、UDP 需要更新 App）在设计稿里是切换选项，开发时每种都要做。
